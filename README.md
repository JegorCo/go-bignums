# go-bignums

Поиск максимума в слайсе последовательно и в восьми горутинах.
Программа генерирует положительные числа и сравнивает время поиска в микросекундах.

Нужны Go 1.24.1 или новее и Make.

## Команды

Собрать программу в `bin/go-bignums`:

```bash
make build
```

Собрать и запустить программу:

```bash
make run
```

Выполнить сборку и запуск через `all` (также можно вызвать `make` без аргументов):

```bash
make all
```

Запустить все тесты:

```bash
make test
```

Запустить подробные тесты `maximum`:

```bash
make test-max
```

Запустить подробные тесты `maxChunks`, включая границы частей слайса:

```bash
make test-chunks
```

## CI

GitHub Actions запускается при push и pull request:
`lint → test → build → run`.

`lint` выполняет `go vet .`. В `test` отдельными шагами запускаются
`make test-max`, `make test-chunks` и `make test`.
Затем выполняются `make build` и `make run`.
Каждый этап начинается только после успешного завершения предыдущего.
